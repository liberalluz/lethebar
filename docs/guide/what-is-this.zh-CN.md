# 这是什么？

[English](what-is-this.md) · 简体中文

你写一个 zip。玩家装上，玩一局。里面没有代码。

## 你写什么

```
my-story.zip
├── manifest.json     这包叫什么、一局从哪开始
├── data/
│   ├── nodes.json    场景：谁出现、有什么选择、通向哪里
│   ├── state.json    数字：钱、体力、信任
│   ├── actions.json  按钮：种田、送礼、离开
│   ├── phases.json   回合、章节、一局什么时候结束
│   └── rules.json    什么之后变什么
├── assets/           图和声音
└── i18n/             每种语言下的文字
```

`nodes.json` 是故事本身。其余文件决定故事能做什么：能花什么、能选什么、
什么时候结束、结束时变什么。

## 一局怎么跑

1. 玩家在包页上装你的包。
2. 引擎打开第一个场景，把文字和选择画出来。
3. 玩家选一个；引擎执行它的效果，走到下一个场景。
4. 到了边界，`phases.json` 和 `rules.json` 决定加什么、扣什么、这一局是否结束。
5. 玩家存档；下次从停下的地方继续。

## 你每天做什么

写场景、调数字、换图。整个循环就这三件。

## 你能做出什么

| 你做的东西 | 玩家拿到什么 |
| --- | --- |
| 一个完整故事 | 装上，从第一页开始 |
| 给别人的故事加一层 | 同一局，换视角、密度或阵容来讲 |
| 一个数字补丁 | 同一局，换成本、换收益 |
| 一个外观 | 同一局，换图和声音 |
| 同一个世界里的另一个故事 | 另一个包，同一个页面 |

## 你做不到什么

- **一种新的玩法。** 卡牌对战、实时战斗、可以走的地图：引擎没有对应的“一步”，
  要它的包装不进去。
- **改别人的故事。** 加一层能改故事怎么讲，不能改故事里发生了什么。
- **把代码放进包里。** 包是数据；引擎是唯一的代码。

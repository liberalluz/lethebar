### Changed

- The shell reflows for a window narrower than 600 px: 12 px margins, a 24 px
  heading, a 44 px minimum button, a column that scrolls when it does not fit,
  and a dialog that takes the width it can get. A phone held upright reads the
  same controls; the wide layout keeps the shape it had.
- The project asks for a sensor orientation instead of a fixed one, and insets
  the shell by the display safe area where the platform reports one.

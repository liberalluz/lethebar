### Added

- A capability request form, so a package author can ask the engine for behaviour
  instead of being told to wait for a batch, and `docs/specs/capabilities.md`
  answers with one of three written outcomes.

### Changed

- `ADR-0010` now describes a package by three axes (form, dimension, trust), says
  what each kind of repository must never hold, and closes with the three
  misreadings the earlier wording invited.
